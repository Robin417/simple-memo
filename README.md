# simple-memo

실행: https://robin417.github.io/simple-memo/ 접속 → 이메일·비밀번호 회원가입 → 메모 입력·저장. 다음에는 로그인합니다. 설치 과정은 없습니다.

RLS: 별도 테스트 사용자로 다른 사용자의 메모 조회 0건·삭제 0건, 소유자 위조 INSERT 거부를 실제 검증했습니다. RLS 활성화, 비로그인 SELECT와 로그인 UPDATE 권한 없음도 확인했습니다.
